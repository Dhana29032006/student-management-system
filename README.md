# Student Management System

## Project Description
A console-based Student Management System built in Python to add, view, update, delete, and search student records. It demonstrates core Python concepts from variables and control flow to file handling, exception handling, and object-oriented programming.

## Features
- Add new student records (ID, name, branch, year, email, phone)
- View all students
- Search students by ID or name
- Update student details
- Delete student records
- Save and load data from a JSON file
- Basic input validation and error handling

## Technologies Used
- Python 3.x
- Built-in libraries: `json`, `os`

## Python Concepts Used
- Variables & Data Types
- Input & Output
- Operators & Type Casting
- Conditional Statements
- Loops
- Functions
- Data Structures
- File Handling
- Exception Handling
- Object-Oriented Programming

## Installation / Setup
1. Ensure Python 3 is installed.
2. Download or clone this project folder.
3. Open terminal/command prompt in this folder.

## How to Run the Project
```bash
python main.py
```

Follow the on-screen menu to manage student records.
